## Опис роботи

У межах лабораторної роботи досліджено роботу хеш-колекцій (`set` та `dict`) із користувацькими об'єктами класу `Product` та виправлено дефект порушення контракту між рівністю об'єктів і їхнім хеш-кодом:
1. Проведено діагностику поведінки множини `unique` та словника `stock` до виправлення, де два екземпляри з однаковим артикулом `code` сприймалися як різні ключі.
2. Доповнено клас `Product` методом `__hash__` (узгодженим із `__eq__` за полем `code`), після чого множина коректно відсіяла дублікати (6 унікальних товарів із 8), а словник перезаписав значення за існуючим ключем (1 запис замість 2).

## Як запустити проєкт

1. Переконайтеся, що на комп'ютері встановлено **Python 3**:
   ```bash
   python --version
   ```

2. Перейдіть у папку лабораторної роботи `lab09`:
   ```bash
   cd lab09
   ```

3. Запустіть скрипт у терміналі:
   ```bash
   python lab09.py
   ```
   *(На Linux або macOS може знадобитися команда `python3 lab09.py`)*
